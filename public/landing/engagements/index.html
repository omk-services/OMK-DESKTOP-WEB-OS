Les objections

Ce qu'on ne fait pas

Quatre lignes que toute la page pourrait résumer. Si l'une d'elles est fausse un jour, c'est le moment de fermer ce site.

Engagement n°01

Pas de SaaS qui vous enferme

Aucun export verrouillé, aucun format propriétaire. Vos données sortent en standard, à n'importe quel palier, sans préavis.

Engagement n°02

Pas d'IA qui apprend de vos données

Vos notes de session ne servent pas à entraîner un modèle public. Le traitement est tracé, l'audit log est exportable, le zéro-PII est une mécanique, pas une promesse.

Engagement n°03

Pas de « book a demo » sans montrer vos données

L'audit de 30 min ouvre votre propre stack — pas une démo préparée. Vous voyez ce qui se passe sur vos vraies notes.

Engagement n°04

Pas de prix inventé

On ne vous annoncera pas un tarif qu'on n'a pas vérifié. Si le chiffre n'est pas publié, c'est qu'il est à calculer sur l'audit.
