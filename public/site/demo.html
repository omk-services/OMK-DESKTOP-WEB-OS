Le pourquoi du comment

Pourquoi la démo n'envoie aucune donnée

Le bureau de démonstration se sert d'un seed local. Vos clics vivent dans la mémoire du navigateur et s'effacent à la fermeture de l'onglet. Voici pourquoi c'est le bon défaut.

  • Pas de piège à données. Vous quittez, vos notes quittent. C'est la définition d'une démo honnête — pas d'inscription forcée, pas d'opt-in discret.
  • Le seed survit à Supabase. Si la base de production est en panne, le seed local prend le relais. La démo reste démontrable. Un coach qui voit une page d'erreur ne s'inscrit pas.
  • Le seed est représentatif. 23 collections pré-remplies, des dizaines d'items lisibles — vous voyez les données que vous tiendrez, pas une version édulcorée.
  • Le branchement est explicite. Quand vous créez un vrai compte, vous passez du seed local à votre propre base. La bascule est affichée, pas silencieuse.
